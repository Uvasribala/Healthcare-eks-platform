# Healthcare-eks-platform
A production-ready microservices platform on AWS EKS

### Architecture
- VPC: 3-tier public-private subnets for Dev, Pre-Prod, Prod
- IaC: Modular Terraform with environment isolation  
- Microservices: User, Product, Payment, Notification
- CI/CD: GitHub Actions -> ECR -> EKS

### Tools Used
- AWS: EKS, EC2, ECR, ALB, Auto Scaling, Route53, IAM, ACM, Secrets Manager, CloudTrail, CloudWatch, CloudFront
- Docker, Kubernetes, Terraform, GitHub Actions, Linux
- Monitoring: Prometheus, Grafana, SNS Alerts
